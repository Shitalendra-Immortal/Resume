# PWA Icons

This folder should contain your PWA icons for offline/install support.

## Required files:
- **icon-192.png** — 192×192 pixels
- **icon-512.png** — 512×512 pixels

## How to generate:
1. Visit [favicon.io](https://favicon.io/favicon-generator/) or [RealFaviconGenerator](https://realfavicongenerator.net/)
2. Upload a square logo or create one with your initials
3. Download the generated icons
4. Place them here as `icon-192.png` and `icon-512.png`

## Temporary workaround:
Until you generate real icons, the PWA will work but won't have a custom icon. The browser will use a default placeholder.

## Quick DIY approach:
Create a simple square design (e.g., your initials on colored background) using:
- Canva (free templates)
- Figma (free design tool)
- Even PowerPoint — make 512×512 slide, add text, export as PNG
